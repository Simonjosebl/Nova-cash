# Product Foundation (Cap. 1)

**Qué es:** app de finanzas personales y colaborativas. **Éxito:** entender tu dinero en < 5s; registrar un movimiento en < 20s.

- **Visión:** la app de finanzas más intuitiva de LatAm; consulta diaria del estado del dinero.
- **Valores:** simplicidad, claridad, cercanía, rapidez, confianza.
- **Diferenciadores:** Nova Insights (motor de reglas, **no IA**), calendario financiero (eventos con emoji, sin puntos), emojis como identidad, Workspaces independientes.
- **Público:** 18–45 años; estudiantes, profesionales, familias, parejas, independientes.
- **Niveles:** 1 Registro → 2 Interpretación → 3 Predicción → 4 Automatización → 5 Asistente. **MVP = Nivel 1 + parte del 2.**

Detalle completo en `PRODUCT.MD` (Cap. 1).
