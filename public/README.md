# public — Estáticos servidos por la web

Archivos servidos tal cual por Vite en la raíz del sitio.

Aquí irán (generados desde `assets/brand/` — ver [`docs/branding`](../docs/branding)):

- `favicon.ico`
- `favicon-16x16.png`, `favicon-32x32.png`
- `apple-touch-icon.png`
- `manifest.webmanifest` (si se habilita PWA)

No poner aquí assets importados por el bundler (esos van en `src/assets/` o `src/shared/assets/`).
