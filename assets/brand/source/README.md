# 📥 Logos originales — súbelos aquí

Coloca en esta carpeta los archivos originales de la marca Nova Cash tal como los tengas
(SVG preferido; si no, PNG lo más grande posible).

Cuando estén aquí, avísame por el chat y los proceso según
[`docs/branding/README.md`](../../../docs/branding/README.md):
favicon `.ico`, iconos de app iOS, splash screens y el SVG del logo para la UI.

Formatos ideales:

- Logo horizontal: **SVG** (o PNG ≥ 2000px)
- Isotipo cuadrado: **SVG** (o PNG ≥ 1024×1024)
- Icono de app: PNG **1024×1024** con fondo sólido
